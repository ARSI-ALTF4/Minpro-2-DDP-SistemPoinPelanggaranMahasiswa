# Ahmad Raihan Sangkan Ladunni 2609116037 (A)
**PENJELASAN SINGKAT PROGRAM:**
Program Sistem Pelanggaran Mahasiswa merupakan PROGRAM yang dirancang dengan Python untuk mengelola data tata tertib kampus secara terstruktur. Program ini dilengkapi sistem login berbasis role menggunakan library pwinput, di mana admin memiliki hak akses penuh untuk melakukan operasi CRUD (Tambah, Lihat, Edit, Hapus), sementara user hanya dapat melihat data pelanggaran. Program ini juga memanfaatkan library PrettyTable untuk menampilkan data dalam bentuk tabel yang rapi serta menerapkan validasi input yang ketat menggunakan conditional statement guna memastikan kevalidan data yang dimasukkan.
